# Bakkerij Sint Hubertus

Prototype voor een eenpagina-website voor Bakkerij Sint Hubertus, Grote Baan 62, 3150 Wespelaar (Haacht).

- Eén bestand: `index.html` (React en Tailwind via CDN, foto's ingebed)
- Openingstijden en "Nu open"-status lopen live mee (Belgische tijd)
- De bestelhulp stelt een bericht samen dat de klant kopieert of mailt. Er wordt niets verstuurd.

Foto's: Unsplash. Vervang ze door eigen foto's van de bakkerij voor livegang.
Contactgegevens komen uit openbare bedrijvengidsen (Gouden Gids, Handelsgids).
